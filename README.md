Estudiant de Desenvolupament d'Aplicacions Multiplataforma (**DAM**) a l'**Institut Nicolau Copèrnic** (Terrassa), enfocat en el desenvolupament backend, l'arquitectura MVC, les bases de dades relacionals i no relacionals, i la creació d'aplicacions completes i segures.
